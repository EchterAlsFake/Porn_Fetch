I know that AI writes better code than me, but the goal was always to write the initial layer myself
and then let AI build on that and correct my mistakes.

However, the problem with that is that it is inefficient and also time-consuming.

With that being said, I already learned a lot of cool stuff, but I am still just at 1% of where I

# Vibe Coding vs. Useful Usage
Recently (8 weeks ago) I started testing and getting used to working with Agents.
Specifically Codex and Antigravity. I started learning about MCP servers, Skills
and also experimented with running local AI models. 

After careful consideration I need to be honest with you. Using AI directly on my PC
boosted my workforce by 10x. It would be absolutely stupid not to use just to have a label on my repo saying: "100% Human Code".
I am still going to school. When I come home I have maybe 2-3 hours and then the day is over. If I was writing the entire
code for my 15 scraper libraries myself, I would burn out faster than you can imagine and we wouldn't make any
progress here.

I just want to assure you that unlike "Vibe Coders" these days I am not going inside Codex and say:
"Yo, do feature X for me" and push that to GitHub.

Each Prompt is well thought and I actually think about what I want to have and how I want a design choice to be and then I 
let AI implement it for me. Apart from that, the important thing is that I actually test the code I ship.
Each version of Porn Fetch gets 2-3 FULL (12 hour) days of entire testing on all platforms and only if absolutely everything
works it will merge into a new release that you can download.

This is fundamentally different from saying: "Claude, make a 10k business for me, don't stop until you made it, make no mistakes" (lmao).

I can understand if you don't like AI and I honestly think it will be a danger for humanity, but not because some software dev writes
his code with it.

If the wrong people use it for evil things it for sure is a bad thing. I wouldn't consider myself one of those though.
