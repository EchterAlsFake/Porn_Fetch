Contributions to this project are accepted through GitHub Pull Requests.
You can open a Pull Request in English and German. It's okay if you
are using an AI model to translate your Pull Request from your language to English.
**DO NOT USE GOOGLE TRANSLATE**

* The CLA grants the project owner rights necessary to use, modify, distribute, commercialize, sublicense, and relicense accepted contributions, including under different or proprietary license terms.
* Opening a Pull Request does not guarantee that the contribution will be accepted or merged.
* Please do not submit code, documentation, or other material that you do not have the legal authority to contribute.

## AI Use in Pull Requests
AI is the future and I use it myself. You can absolutely use AI to contribute code. However, 
there are certain conditions:

- Be transparent about which model you used with which settings
- Do not use Low-End Models like Gemini 3.6 Flash or GPT 5.5 mini
- Always enable high reasoning and give AI the full context
- You MUST understand each line of code and be able to give an explanation if asked
- Your Pull Request must be written by YOU not an AI!
- You must have tested your code extensively

### Security & Anti-Malware Policy
Submitting code intended to compromise security, introduce backdoors, extract secrets, or install malware is strictly prohibited. Any attempt to introduce malicious code will result in:

1. **Immediate Block & Ban** from contributing to this repository and organization.
2. **Immediate Report** filed with GitHub Trust & Safety for Acceptable Use Policy violations.
3. **Reversion of the PR** with a publicly documented security advisory detailing the malicious payload.
